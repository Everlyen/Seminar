Essentially, in this context it is the use of sequence information available from sequencing projects to infer the relationships between proteins. 
These comparisons are normally based on multiple sequence alignments (MSA). This vital field allows for multiple types of analysis: 
Gene function prediction, evolutionary biology (the traditional tree of life we're used to is a phylogenetic tree which shows the evolutionary history between a set of sequences, nowadays based on comparisions of the rRNA )
