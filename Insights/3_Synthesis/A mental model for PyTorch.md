I want to have a clear mental model for how PyTorch implements neural networks from scratch. This assumes that we have a conceptual understanding of how neural network training works, but what we need is a working understanding of PyTorch. 


A PyTorch tensor is different from a numpy array in that it stores not just the array, but also how it was created. This is the first general idea that needs to be solidified.
