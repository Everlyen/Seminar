## What is it? 🤔

It is a four part numerical code that informs us about the types of catalytic reactions that enzymes would catalyze

## Where I learnt this 🕶
[[Language Modeling Materializes a World Model of Protein Biology]]
Here they used EC number classification as a way to understand whether a large protein language model groups proteins with similar function in the embedding space
## Example application 💡

EC 1.1.1.1 is an example of an EC number 

(The following is from [Enzyme Commission number - Wikipedia](https://en.wikipedia.org/wiki/Enzyme_Commission_number))

For example, the [tripeptide aminopeptidases](https://en.wikipedia.org/wiki/Tripeptide_aminopeptidase "Tripeptide aminopeptidase") have the code "EC 3.4.11.4", whose components indicate the following groups of enzymes:

- _EC 3_ enzymes are hydrolases (enzymes that use [water](https://en.wikipedia.org/wiki/Water "Water") to break up some other molecule)
- _EC 3.4_ are hydrolases that act on [peptide bonds](https://en.wikipedia.org/wiki/Peptide_bond "Peptide bond")
- _EC 3.4.11_ are those hydrolases that cleave off the amino-terminal [amino acid](https://en.wikipedia.org/wiki/Amino_acid "Amino acid") from a [polypeptide](https://en.wikipedia.org/wiki/Polypeptide "Polypeptide")
- _EC 3.4.11.4_ are those that cleave off the amino-terminal end from a [tripeptide](https://en.wikipedia.org/wiki/Tripeptide "Tripeptide")
