## 1. Install Obsidian
Download from [obsidian.md](https://obsidian.md) and install.

## 2. Open the vault
File → Open folder as vault → select the Seminar folder on your computer.

## 3. The basics of editing
- Click any note to open it
- Just start typing — it works like a normal text editor
- `[[word]]` creates a link to another note
- `- [ ]` creates a checkbox

## 4. Saving your changes (git)
When you've added something, open the Obsidian Git panel (left sidebar) 
and hit **Commit and push**. That sends it to everyone.
