## 1. Install Obsidian
Download from [https://obsidian.md](https://obsidian.md/download) and install.

## 2. Open the vault
Open folder as vault → select the Seminar folder in the shared drive (labmeetingslides > 202610000) as a starting point.

![[Opening a vault.png|308]]
## 3. The basics of editing
- Click any note to open it
- Just start typing — it works like a normal text editor
- `[[word]]` creates a link to another note
- `- [ ]` creates a checkbox
- Quickly add a new [[Concept template|concept]] or [[Literature template|paper]] by using the templates provided
## 4. Installing plugins (optional)
Go to settings
![[Opening settings.png]]

Open the list of community plugins. 
![[Open community plugins page.png|566]]

And search for 
- [Git](obsidian://show-plugin?id=obsidian-git) - Only necessary if working remotely. If working from your computer at work this isn't necessary as you'll be working directly in the folder everyone else is modifying. (repository link: ) 
- [Dataview](obsidian://show-plugin?id=dataview) - Uses DQL query language to filter and display those resulting searches in a graphical way. This renders the dataview codeblocks that exist within the different pages to show related items, not necessary, but useful.

Importantly you must **install** and **enable** the plugins for them to be active. 

## 5. Saving your changes (If you chose to install Git plugin)
This is only necessary if you'd like to work remotely. 

When using the vault for the first time you can pull all the changes that have been made since the initial version of the vault.
When you've added something, open the Obsidian Git panel (left sidebar), pull the repository first, 
and then hit **Commit and push**.

![[Using Git plugin.png]]

> **Important to note**
You'll need to discard the .json files before committing and pushing. If not you'll receive an error which doesn't allow you to commit.
